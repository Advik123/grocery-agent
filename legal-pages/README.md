# Groceries-Agent Legal Pages

Static pages for Meta app publishing:

- `/privacy` - privacy policy
- `/data-deletion` - data deletion instructions

## Deploy on Vercel

Deploy this `legal-pages` folder as a static Vercel project.

After deployment, use these URLs in Meta:

```text
Privacy policy URL:
https://your-vercel-domain.vercel.app/privacy

Data deletion instructions URL:
https://your-vercel-domain.vercel.app/data-deletion

App domains:
your-vercel-domain.vercel.app
```

If you later add a custom domain, replace the Vercel domain with your custom
domain in Meta's app settings.
